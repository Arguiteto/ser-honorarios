# Calculadora de Projeto — Método S.E.R.

Ferramenta de precificação de honorários arquitetônicos baseada no **Método S.E.R.**  
Desenvolvida para estudantes e profissionais de arquitetura e urbanismo no Brasil.

**[→ Acessar a calculadora](https://seu-usuario.github.io/calculadora-ser)**

---

## O que ela faz

Calcula o valor real de um projeto de arquitetura em cinco etapas encadeadas:

| Etapa | O que cobre |
|-------|-------------|
| **① Escritório** | Custos fixos mensais + capacidade produtiva → hora técnica |
| **② Fases** | 14 fases do projeto (NBR 13531/13532) + visitas técnicas |
| **③ Impostos** | ISS, IRPJ+CSLL, PIS+COFINS, ART/RRT, outros encargos |
| **④ Desconto** | Percentual ou valor fixo + condições de pagamento parcelado |
| **⑤ Proposta** | Resumo financeiro completo com exportação PDF e cópia rápida |

## Como usar

1. Baixe o arquivo `index.html`
2. Abra no navegador (funciona offline, sem instalação)
3. Preencha as etapas em ordem usando o stepper
4. Na etapa ⑤, exporte como PDF via `Ctrl+P` ou copie o resumo
