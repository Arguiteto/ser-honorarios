Mapoteca — Busca de terreno

Localizar arquivo do terreno

Informe o CEP do local. O sistema busca o endereço, geocodifica o ponto, tenta coletar bairro/lote/quadra/área no SIMGEO e procura a prancha correspondente na Mapoteca oficial.

Ajuda a posicionar o lote dentro do CEP.
Use só se souber; ajuda quando a Mapoteca usa nome antigo.

Observação: a Mapoteca pode publicar PDFs por bairro, loteamento, setor ou folha. Quando não houver API pública suficiente para confirmar o lote exato, o sistema mostra o arquivo mais provável e alternativas.

Resultado

A ficha aparece aqui com área identificada, dados do terreno e link do arquivo encontrado.

Digite o CEP e clique em “Buscar terreno”.
Consulta SIMGEO

Coleta de dados urbanísticos

Informe uma coordenada ou um CEP com número. O sistema tenta localizar o ponto e consultar as camadas públicas disponíveis no WebApp do SIMGEO/CTM.

Use latitude/longitude em WGS84. Ex: Google Maps.
CEP sozinho não aponta o lote; use número para melhorar a precisão.
O sistema identifica a cidade e lista os portais de geoprocessamento disponíveis para a região.

Resultado

A ficha aparece aqui depois da consulta. Os campos dependem das camadas que o SIMGEO deixar consultar publicamente.

Digite uma coordenada ou CEP e clique em “Consultar dados”.
